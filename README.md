# Mini Ticket Tracker

A small support-ticket tracker: a REST API, a MySQL database and a lightweight UI.

| Part       | Stack                | Folder      |
|------------|----------------------|-------------|
| API        | Laravel (PHP)        | `backend/`  |
| Database   | MySQL                | —           |
| UI         | Angular              | `frontend/` |

## Repository layout

This is a single repository (monorepo) — one clone gets both apps:

```
mini-ticket-tracker/
├── backend/    # Laravel REST API
└── frontend/   # Angular single-page UI
```
